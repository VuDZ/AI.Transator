# Формат словаря

Канон Markdown для полного корпуса вселенной и для рабочего словаря книги. Менять этот файл, если меняется парсер.

Модель ест этот текст как есть. Комментарии — часть промпта, не побочные метаданные.

## Два файла, один формат

| Файл | Роль |
| --- | --- |
| Полный корпус | Живёт долго, копится, правится руками. Может быть огромным. |
| Рабочий словарь книги | Пересечение корпуса с текстом этой книги (+ явные ручные дописки). Стабилен на весь перевод. |

Писатель не меняет порядок записей корпуса. Компилятор сохраняет относительный порядок из корпуса: это держит префикс стабильным между повторными compile на том же входе.

Рабочий словарь может не содержать ни одной `##`: пересечение с книгой бывает пустым, в файле остаются заголовок и преамбула. Парсер такой MD читает. Compile полного корпуса без единого `##` — ошибка.

## Каркас документа

```markdown
# Warhammer 40k

Preamble: нормы издания, ты/вы, что не переводим глобально.
Пустые строки допустимы. Текст до первой `##` — преамбула.

## Librarian
- ru: Библиарий
- type: title
- notes: Не использовать «Библиотекарь».
- do-not-use: Библиотекарь
- aliases: Librarians, Librarian's

## Adeptus Astartes
- ru: Адептус Астартес
- type: organization
- notes: не склоняется
- aliases: Astartes
```

Правила:

- Ровно один заголовок `#` — название корпуса или книги.
- Всё между `#` и первым `##` — преамбула. Попадает в `StablePrefix` целиком: вселенная, издание, ты/вы, что не переводим. Не лор и не список терминов — термины ниже в `##`.
- Каждая запись начинается с `## {English}`. Текст заголовка — каноническая английская форма.
- Поля записи — список `- key: value` (ключ в нижнем регистре).
- Неизвестные ключи парсер не роняет: сохраняет как сырые пометки или игнорирует с предупреждением. В v1 достаточно игнорировать с логом, не теряя известные поля.
- HTML в значениях не используем.

## Поля записи

| Ключ | Обязателен | Смысл |
| --- | --- | --- |
| `ru` | да | Канонический русский вариант этого издания |
| `type` | нет | См. типы ниже. Дефолт: `other` |
| `notes` | нет | Пометки для модели: не склоняется, род, «в этом цикле только так», источник |
| `do-not-use` | нет | Запрещённые русские варианты, через запятую |
| `aliases` | нет | Английские варианты для матчера, через запятую |

Конфликт «Librarian = Библиарий | Библиотекарь» в рантайме не голосуется. В корпусе один `ru`, остальное в `do-not-use` или `notes`.

## Типы (`type`)

| Значение | Примеры |
| --- | --- |
| `name` | Ciaphas Cain, Eisenhorn |
| `title` | Librarian, Chapter Master |
| `organization` | Adeptus Astartes, Inquisition |
| `artifact` | bolter, chainsword |
| `geography` | Holy Terra, Cadia |
| `formula` | litanies, set phrases |
| `other` | всё остальное |

Имена и термины — один словарь. Отдельного «только имена» файла нет.

## Матчер

Компилятор считает запись встретившейся в книге, если канонический English **или любой alias** найден в plain text книги.

Правило вхождения v1 (не токен `\b` движка regex по умолчанию):

- сравнение без учёта регистра;
- слева и справа от совпадения нет ASCII-буквы `[A-Za-z]`;
- дефис, апостроф, типографский `’` и начало/конец строки — допустимые границы.

Следствия:

- `Astartes` матчит `Astartes`, `Astartes'`, `anti-Astartes`;
- `Chapter` не матчит `Chaptersomething`;
- многословные термины (`Adeptus Astartes`) ищутся как целая фраза с теми же границами по краям.

Ложные срабатывания вроде английского `Chapter` = «глава книги» vs «орден» матчер не решает. Это пометки в `notes` и дисциплина корпуса. В v1 не делаем NER и не просим модель фильтровать compile.

## Слияние

При дописывании в существующий корпус ключ записи — канонический English, сравнение ordinal ignore case.

- Уже есть — не затираем `ru`. Новые `notes` / `do-not-use` / `aliases` можно дописать, если их ещё нет.
- Нет — добавляем в конец, не пересортировывая документ.
- Автоматический overwrite канона запрещён. Эпоха 05 только предлагает; человек принимает.

## Что не является словарём

- JSON/YAML рядом «для машины». Единственный источник — MD.
- Словарь на чанк.
- Подмешивание кандидатов в рабочий файл во время перевода.
