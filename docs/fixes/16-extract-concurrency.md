# Сверка эпохи 16 — Параллельный glossary extract

Дата: 2026-10-09.
Контракт: [16-extract-concurrency.md](../epochs/16-extract-concurrency.md).

## Проверено
- CLI принимает --concurrency и передаёт его через сервис в ExtractRunContext; default отдельно задаётся Translator:ExtractMaxConcurrency=1.
- 0/9 и --list-pairs + --concurrency отвергаются до вызова сервиса / LLM.
- Первый запрос прогревает prefix отдельно, затем in-flight ограничен N. Новый CLI-флаг перекрывает default 1; translate не менялся.
- Обратный порядок завершения второго/третьего ответа сохраняет исходный порядок словаря и ru первого по плану ответа.
- CompletedSteps и PendingOutputs пишет один участник; сериализация IRunProgress сохраняется в RunProgressReporter.
- При ошибке второго запроса третий дожидается, оплаченный ответ остаётся PendingOutputs; четвёртый не запускается.
- Resume с другим N вызывает только недостающие запросы, использует готовый pending ответ, затем очищает буфер.
- Отмена дожидается завершения текущих задач и не теряет уже записанный поздний ответ.
- Старый checkpoint без PendingOutputs читается и продолжается.
- При ошибке сохранения слияния изменения in-memory Completed/Ready откатываются до отпускания gate, чтобы следующая запись не утверждала неуспешный шаг.
- Системный префикс, нарезка пары, retry policy, формат словаря и транспорт не менялись.
- Проверки: Release build и unit-тесты через Roslyn MCP; тесты без сети.

Замечаний по контракту, требующих отдельной правки кода, не обнаружено.

## Ограничения
- До завершения предыдущего шага поздний успешный ответ находится в state, а не в --out. Work-dir требуется сохранить для resume.
- При конечной ошибке команда может ждать другие in-flight до их завершения/таймаута; это позволяет сохранить оплаченные успешные ответы.
- PendingOutputs может увеличивать размер checkpoint, если ранний запрос медленный.
- Как и до эпохи 16, записи out/state не являются общей атомарной транзакцией: завершение процесса во время файловой записи не покрывается гарантией штатной обработки ошибок/отмены.
- Живой платный extract не запускался.
