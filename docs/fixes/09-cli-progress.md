# Правки после эпохи 09

Статус: **принята**. 153 теста зелёные.

Сошлось с контрактом:

- категории `System.Net.Http`, `System.Net.Http.HttpClient` и `System.Net.Http.HttpClient.llm` зафиксированы на `Warning`; служебные Start/Sending POST не попадают в Information
- `Spectre.Console` подключён только к Cli; Core знает только `IRunProgress`
- прогресс и таблицы usage пишутся через отдельную Spectre-консоль в stderr
- до завершения запроса виден текущий чанк или путь пары; после шага — done/total, ETA, последний и суммарный usage
- ETA считается через `TimeProvider` по среднему времени завершённых шагов; до первого результата значение не выдумывается
- translate при `--resume` считает только оставшиеся чанки; уже готовые повторно в total не входят
- extract заранее разворачивает пары и крупные фрагменты в шаги, label содержит индекс и путь
- `completion_tokens` читается в nullable `LlmResponse.CompletionTokens`; отсутствие поля сохраняется как null
- суммарная статистика учитывает ответы повторных попыток и число неуспешных шагов

## Не дефект 09

- Цена в рублях и файл истории usage остаются вне эпохи.
- Бар обновляется на границах шагов; внутри нестримингового HTTP-запроса показывается текущая подпись, но процент и ETA не тикают посекундно.
- Живой прогон провайдера не является unit-тестом приёмки.
