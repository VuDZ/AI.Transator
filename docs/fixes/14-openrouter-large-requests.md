# Сверка эпохи 14 — Большие запросы OpenRouter

Дата: 2026-10-08.
Контракт: [14-openrouter-large-requests.md](../epochs/14-openrouter-large-requests.md).
Статус: реализация сверена; замечаний, требующих отдельной правки кода, не обнаружено.

## Проверено
- Независимые входной и выходной бюджеты; полный контекст ограничивает их сумму. Коэффициент расширения и reasoning reserve уменьшают исходный чанк.
- Новый профиль считает оценку склеенного HTML; legacy сохраняет прежние границы нарезки.
- Профиль Haiku: вход до 90000, completion до 128000, multiplier 2, SSE, thinking off и cache TTL 1h. Example без ключа; Local не изменён.
- SSE: comments, multiline data, фрагментированное UTF-8, пустые choices и повтор finish в usage, EOF с DONE без завершающего пустого события.
- Content содержит только перевод. Usage сохраняет prompt/cached/completion/reasoning.
- Обрыв, malformed SSE, mid-stream error и таймаут после заголовков не принимаются как завершённый ответ. Внешняя отмена пробрасывается.
- Настройки кеша ограничены openrouter; стабильный session_id не зависит от HTML текущего чанка. Прогрев эпохи 13 сохранён.
- Resume нового профиля отвергает смену настроек планирования до перезаписи файлов; старый checkpoint с переходом на новый профиль также отвергается. После возврата настроек done-чанки повторно не вызывают LLM.
- Сборка через run_dotnet_build успешна; run_dotnet_test: 216/216. Тесты не вызывают платный API.

## Практические ограничения
- Реальный перевод книги и фактические cache hits через OpenRouter не проверялись: профиль нужно применить к локальному конфигу с подходящим ключом.
- length/4, коэффициент 2 и reasoning reserve — оценки. Они не гарантируют отсутствие finish_reason=length на произвольном тексте.
- Streaming читает ответ постепенно; прогресс CLI по-прежнему показывает завершённые чанки, без показа текущих токенов.
- Минимальный кешируемый prefix и доступность кеша определяются провайдером. Cache TTL 1h не гарантирует sticky routing дольше его собственного таймера.
- Коммит отменён по указанию пользователя. Изменения реализации ранее добавлены в индекс, этот файл не добавлялся.
