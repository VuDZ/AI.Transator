# Правки после эпохи 07

Статус: **принята**. 139 тестов зелёные. `--pairs` читает mapping; без флага extract остаётся i к i. `--max-pairs` режет уже развёрнутый список.

Сошлось с контрактом:

- точечная пара A=Y: один LLM, VariableContent — A и Y, не B/C/X
- блок A..B = X..Y: два вызова в kept-порядке
- нет пути / разные длины блока / дубль пути — ошибка, LLM не вызван
- `--max-pairs 2` из трёх пар — два вызова; без `--pairs` или N ≤ 0 — ошибка до HTTP
- `--list-pairs` + `--pairs`, `--pairs` без `--out` — exit ≠ 0
- парсер: комментарии, `=`, `..`; пример Dawn of Fire 1 — 2 точки + 1 блок; `\` и регистр сходятся
