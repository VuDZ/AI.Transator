## До эпохи 03

1. **Пустой рабочий словарь нельзя прочитать обратно.** Если в книге нет ни одного термина, `Write` даёт только `#` + преамбула, без `##`. `Parse` на таком файле падает (`no glossary entries`). Compile при этом завершается 0. Translate потом не откроет `--glossary`. Либо разрешить 0 записей в парсере, либо явная ошибка compile «ничего не сошлось».
