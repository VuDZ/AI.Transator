# Сверка эпохи 15 — Проверка английского и полезные повторы

Дата: 2026-10-09.
Контракт: [15-translation-validation.md](../epochs/15-translation-validation.md).
Статус: реализация сверена; замечаний, требующих отдельной правки кода, не обнаружено.

## Проверено
- Одиночное The и The Who принимаются с warning, без повторной оплаты полного чанка.
- Связная английская проза, в том числе среди русского текста и через inline HTML, остаётся fail с коротким контекстом.
- Проверяются видимые текстовые узлы HTML; entity decoding исключает ложные совпадения в именах entities. Комментарии, атрибуты, head/style/script не проверяются.
- Смешанные Unicode-слова и идентификаторы не дают ложного служебного слова. Исключения протокола эпохи 12 проходят прежние тесты.
- Warning ограничен 3 сообщениями на ответ, диагностический контекст — 120 символами.
- Feedback — отдельный user message перед исходником. StablePrefix, cache_control и исходный HTML остаются прежними. Полный отвергнутый ответ не пересылается.
- Feedback ограничен 600 символами с сохранением инструкции. При недостаточном MaxInputTokens или ContextWindowTokens он пропускается. HTTP-ретрай сам не создаёт feedback.
- Число попыток, concurrency, нарезка и resume не изменены.
- run_dotnet_build Release: успешно.
- run_dotnet_test Release: 241/241; тесты без сети, включая успешный чанк с предупреждением, отказ/исправление со вторым запросом и оба ограничения бюджета.
- Debug-сборка не завершилась из-за DLL, занятой запущенным ai-translator (81060); процесс не прерывался. Для проверки использован отдельный каталог Release.
- Коммита нет по действующей просьбе пользователя.

## Что установлено по реальному чекпоинту
У 0001-0000 сохранился error.txt с English function word: The, но текущий state.json уже done, а сохранённый translated.html не содержит The. Отклонённый ответ не сохраняется, поэтому точный контекст того исторического отказа установить нельзя. Рабочие файлы книги не менялись.

## Ограничения
- Warning допускает одиночное непереведённое слово; его нужно вычитать. Это согласованный в контракте компромисс эвристики.
- Длинные английские названия/цитаты со служебными словами всё ещё могут дать fail.
- Тесты доказывают передачу feedback и обработку ответа, но не улучшение качества живой модели; платный повтор книги не запускался.
- Запущенный процесс использует прежнюю сборку до завершения и последующей пересборки/перезапуска.
