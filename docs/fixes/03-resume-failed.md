# Правки после эпохи 03 — resume Failed и диапазон

Статус: **закрыто в коде** вместе с этой заметкой.

Эпоха 03: `--resume` не зовёт LLM для чанков `done`; `state.json` помнит диапазон; другой `--chapters` — отказ. Эпоха 12 сознательно не трогала повтор `Failed`.

## Дефекты

1. **`Failed` при resume не повторялся.** После исчерпания `MaxRetries` (402/502/503 или валидатор) чанк помечался `failed` и в EPUB клался английский исходник. Следующий `--resume` пропускал эти чанки: бар `0/0`, LLM не вызывался, вторая глава оставалась на английском. Контракт: resume повторяет `failed` и `pending`; `done` не трогает. Если повтор снова исчерпал ретраи — статус `failed`, exit ≠ 0, частичный EPUB.

2. **`--resume` без `--chapters` не брал диапазон из `state.json`.** Пустой флаг считался «вся книга» и расходился с чекпоинтом (`Cannot resume: --chapters range does not match the checkpoint.`). Контракт: без `--chapters` — диапазон из `state.json`; явный другой диапазон — отказ, как в 03.

Work-dir по умолчанию не меняется: `{stem}.work` рядом с `--out`.
