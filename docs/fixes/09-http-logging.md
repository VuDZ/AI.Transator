# Правка эпохи 09 — Убрать служебные HTTP-логи клиента llm

Дата: 2026-10-09.
Запрос: в консоль вновь попадают Information-сообщения LogicalHandler / ClientHandler с Start processing и Sending HTTP request.

## Причина уязвимости
appsettings.json задаёт Warning для HTTP, но AddTranslator оставляет включёнными стандартные логгеры IHttpClientFactory. Тишина зависит от применённых настроек. Прежний тест вручную регистрировал фильтры Warning, не проверяя verbose-конфигурацию с настоящей регистрацией клиента.
Источник конкретного переопределения в сообщённом запуске не установлен: в исходном Local секции Logging нет, проверенный Release appsettings содержит Warning. Для исправления эта зависимость устраняется.

## Контракт правки
- При регистрации именованного клиента llm отключить его служебные логгеры через RemoveAllLoggers.
- Start/Sending/Received/End от System.Net.Http.HttpClient.llm не выводятся даже при Information/Trace и более конкретных настройках категорий.
- LogWarning/LogError переводчика и провайдера, прогресс и usage сохраняются; логирование других клиентов не отключать.
- Настройки Warning в appsettings оставить.
- Не менять запросы, модель, ключ, streaming, timeout, ретраи или словарь.
- Тест использует AddTranslator, AddConfiguration и verbose-настройки без ручных фильтров подавления. POST — только mock handler; проверить тишину llm, видимость другого клиента и application warning/error.
- Сборка/тесты через Roslyn MCP. Коммит не создавать по действующей просьбе пользователя.

Статус: **исправлено и проверено**.

## Сверка после реализации
- AddTranslator регистрирует llm с RemoveAllLoggers; локальный конфиг и настройки запроса не менялись.
- Тест при Information и Trace, включая конкретные категории LogicalHandler/ClientHandler, не получает служебных HTTP-сообщений llm.
- В том же тесте другой HTTP-клиент выводит Sending HTTP request; application warning/error также видны.
- Сборка Release успешна; все 242 теста прошли через Roslyn MCP, без сети.
- Отклонений от контракта эпохи 09 после этой правки не обнаружено.
- Для работающего процесса требуется завершение и запуск обновлённой сборки. Коммита нет.
