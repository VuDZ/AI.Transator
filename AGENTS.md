# Правила агентов

Читать вместе с `docs/README.md`. Cursor дублирует это в `.cursor/rules/`.

## Инструменты

Код, тесты, сборка, NuGet, правки C# — MCP `user-rsolyn_mcp`, не шелл и не прямые файловые патчи хоста.

Исключение: `git add` / `git commit` на `master`.
Если нужной MCP-операции нет — сказать об этом, не молча уйти в шелл.

Шелл хоста — Windows PowerShell 5.x. Не `&&` / `||`; цепочка через `;` или отдельные вызовы.

Перед семантикой C#: `load_workspace`. Сборка: `run_dotnet_build`. Тесты: `run_dotnet_test` / `run_specific_test`.

## Коммиты

В `master` пишет только этот агент. После успеха — сразу commit, без `status`/`diff`/`log` и без дампа изменений. Не push. Не коммитить секреты.

Сообщение — Conventional Commits, английский, одна строка: `docs:`, `feat:`, `fix:`, `chore:`, `refactor:`, `test:`.

Комментарии в коде — только английский. Документация в `docs/` может оставаться русской.

## Решения

Спор, улучшение «заодно», смена скоупа эпохи или формата словаря — спросить человека. Сначала `docs/`, потом код.

## Продукт

Эпохи 00→06 по порядку. Не реализовывать `docs/backlog.md` без явной просьбы.

После сдачи эпохи: сверить с `docs/epochs/0X-*.md`. Замечания писать в `docs/fixes/0X-*.md` и коммитить. Код по fixes — отдельным шагом, не раздувать скоуп ревью.
